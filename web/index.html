微信公众号 · 网页模式

不需要 AppSecret。先在专用 Edge 扫码并核对账号，然后选择文章自动填入。请保留浏览器窗口。

目前试验填写标题、作者、摘要、富文本正文、插图及封面，并尝试保存草稿。请在微信页面核对实际样式和裁剪后正式发表；新版仍需真实账号验证。

官方接口设置（可选，网页模式无需填写）

按你的设置，AppID 和 AppSecret 明文保存在本机 .state/settings.json；不会放进文章目录或回显到日志。

微信需要准备什么？

  1. 公众号后台提供的 AppID 和 AppSecret。
  2. 将本机当前网络的实际出口 IP 加入微信接口 IP 白名单。
  3. 确认账号有草稿／发表接口权限。AppID 本身不能证明权限。

不需要为了本文发布功能配置消息接收服务器 URL、消息 Token 或 EncodingAESKey。
